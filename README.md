# Student Portfolio

This repository contains a static portfolio for a fourth-year Computer Engineering
student at Bitlis Eren University.

## Accuracy status

This version limits personal skill claims to information confirmed by the student:

- Python — basic;
- C# — beginner, currently studying;
- Arabic — native;
- Turkish — C1;
- English — B1.

The project cards clearly separate technologies found in repositories from skills
the student can personally claim. Projects were built with substantial AI assistance
and are being reviewed, tested, and simplified as learning exercises.

## Privacy

The site does not publish a school ID, GPA, personal email address, phone number, or
unconfirmed social profile. Professional contact details can be added later after
the student confirms them.

## Local development

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```

## Technologies present in this repository

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Docker and Nginx configuration

These technologies describe how the current repository is implemented. They are
not automatically presented as the student's personal technical skills.

## Current status

This portfolio remains a work in progress and should stay private until the linked
projects have been reviewed and the student can explain the claims included here.
